The MathMaster digital learning platform is developed to train students in elementary arithmetic tasks.
The current project seeks to address the disengagement that usually stems from traditional and often intimidating approaches of math instruction.

The platform leverages the latest developments in web technologies, using React, Node.js, and PostgreSQL.
One of the key functions that the MathMaster offers is an adaptive quiz problem generator, which adjusts the complexity of quizzes according to individual performance metrics.
It should be noted that the project includes the unique functionality, which allows to adapt the user interface based on metadata and specific demographic characteristics. 
This means that users will enjoy the "Rookie" design theme for users aged 6 to 10 and the "Pro Circuit" for ages 11 to 14.

To motivate users to learn through the process of gamification, the MathMaster includes such elements as experience points, achievements, daily streaks, levels, and trophies.
